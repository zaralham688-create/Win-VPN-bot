# راه‌اندازی ربات WIN VPN

## فایل‌ها
- `index.js`: کد ربات
- `package.json`: وابستگی‌ها و فرمان شروع
- `.env.example`: نمونه متغیرهای محرمانه

## قبل از اجرا
در پنل میزبانی، این متغیرهای محیطی را تعریف کنید:
- `BOT_TOKEN`: توکن ربات از BotFather
- `ADMIN_ID`: شناسه عددی تلگرام مدیر
- `CARD_DETAILS`: شماره کارت و نام صاحب کارت برای نمایش به خریدار
- `SUPPORT_USERNAME`: نام کاربری پشتیبانی، مثل @YourSupport

فرمان شروع باید `npm start` باشد.

## نکات مهم
- قیمت بسته‌ها در ابتدای `index.js` نمونه/نامشخص است و باید در کد اصلاح شود.
- پس از تأیید رسید، مدیر باید کانفیگ مشتری را به‌صورت پیام متنی در چت خصوصی ربات بفرستد؛ ربات آن را برای مشتری ارسال می‌کند.
- این نسخه رسید را به مدیر می‌فرستد، اما پرداخت بانکی را خودکار بررسی نمی‌کند. مدیر باید واریز را در حساب بانکی خودش بررسی کند.
- فایل `orders.json` برای نگهداری سفارش‌ها ساخته می‌شود. مطمئن شوید فضای میزبانی فایل‌ها را پس از راه‌اندازی مجدد حفظ می‌کند.
- فقط از این ربات برای فروش سرویس‌هایی استفاده کنید که مجاز به ارائه و میزبانی آن‌ها هستید.
